Script developed during my Doctoral studies at McGill to analyze data presented in my thesis and publications. Programming languages include Python and Fiji (ImageJ) macros.
'fiji_scripts' inlcudes scripts used for image processing throughout my work.
'curvature_taxol' includes scripts used in Chapter 3 of my Thesis, titled 'DCX Prefers and Induces the Compacted Microtubule State', published in Current Biology (https://doi.org/10.1016/j.cub.2025.07.080).
'DualColor' includes scripts used for image processing and analysis of data published in eLife (https://doi.org/10.7554/eLife.66975)
'dynamics' includes scripts used in Chapter 2 of my Thesis, titled 'Cooperative Modulation of Microtubule Dynamics by DCX' and have been used for data analysis is various mnuscripts (https://doi.org/10.1101/2025.06.30.662375, https://doi.org/10.1101/2024.05.27.596091)
